# Portfolio profesional — SMR

Portfolio web personal creado con:

- HTML5
- CSS3
- JavaScript

## Cómo abrirlo

1. Descarga/descomprime la carpeta.
2. Abre `index.html` con tu navegador.
3. No necesita servidor ni instalación adicional.

## Personalización importante

Antes de publicarlo, modifica en `index.html`:

- `tuemail@example.com` por tu email.
- El enlace de LinkedIn.
- El enlace de GitHub.
- Si quieres, añade tu nombre y una fotografía profesional.

También puedes cambiar los textos de proyectos y habilidades según los conocimientos
que hayas adquirido durante el curso.
